# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, accept constructive feedback, and focus on what is best for the community. Harassment, discrimination, personal attacks and unwelcome advances are not tolerated.

Report problems privately to the maintainers through GitHub's "Report a vulnerability / contact" options on the repository or the email listed on the maintainers' GitHub profiles. Maintainers may remove comments, commits or contributors that violate these standards.
