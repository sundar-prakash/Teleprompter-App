How it works

Ready in under a minute.

  1. Add your script

    Type or paste it, or import a PDF, Word document, subtitle file or text file.

  2. Set it up

    Choose a reading mode, text size and pace. Mirror it if you're using a rig.

FAQ

Questions, answered.

Is it really free?

Yes. No ads, no in-app purchases and no subscription. The source code is MIT-licensed.

Which Android versions are supported?

Android 7.0 (Nougat) and newer. Picture-in-picture needs Android 8.0+.

My PDF imports as empty. Why?

The PDF is probably a scanned image without selectable text. Teleprompter reads the text layer of a PDF; it doesn't do OCR yet. Copy the text into a .txt or .docx file, or paste it into the editor.

Can I use it with a beam-splitter / glass teleprompter rig?

Yes. Use the mirror and vertical-flip buttons in the prompter so the reflection reads correctly.

Can the script float over Zoom, Meet or my camera app?

Yes. Tap "Float over other apps" and allow "Display over other apps" when Android asks. You can move, resize and fade the window.

Do you see my scripts or videos?

No. They never leave your phone unless you share them yourself. See the privacy policy.
